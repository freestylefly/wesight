## Notarization Recovery

- The v1.0.11 macOS apps passed Apple notarization. Its Intel DMG query lost network access, and the Apple Silicon DMG query reached the 30-minute CLI timeout while processing continued at Apple.
- The initial v1.0.12 Intel job failed during application notarization after a network timeout, before producing a DMG. The Windows job passed.
- Applications and DMGs are submitted once. Network failures and 30-minute wait timeouts resume the original request, with four application waits and six DMG waits.
- Invalid notarization results and authentication failures stop the build before stapling.
- Failed Mac jobs preserve the signed application archive and generated DMG as pending-notarization artifacts. The publication job collects the verified platform artifacts.
- Regression tests cover network recovery, timeout recovery, rejected submissions, authentication failures, bounded retries and password redaction.
- The recovery workflow checks out the immutable v1.0.12 application source and overlays only the current notarization helpers. Its provenance records both commits. Runtime files are built from the release tag.
- Apple Silicon run 42457249790 passed application and DMG notarization, ticket validation, Gatekeeper and architecture checks. The downloaded artifact also passed local signature, ticket, version and architecture checks.
- Intel recovery run 42460423019 received Apple's acceptance for request `4fb237ba-432c-4218-87b4-e83d6b283a02`, but its runner repeatedly lost the CloudKit connection during ticket validation. The preserved signed archive can be resumed after comparing its SHA256 against Apple's accepted submission log.

## UI and Remaining Limitations

- Ciyuan API desktop UI and routing verification are recorded in `v1.0.11-verification.md`. The user tested the local development build.
- Live Ciyuan API inference has not been automatically verified for every account model.
